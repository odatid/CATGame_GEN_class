# CATGame_GEN

オープンキャンパス演習用ツール。**EMS（Ends and Means Structure／手段目的構造）を高校生が自分の手で埋めて、猫テーマのゲーム案を1本にまとめる。**

ツールは案を自動で作って配るものではありません。生徒が書いた「目的・手段・制約」を点検して返します。
生成AIのAPIは使いません。プロンプトは「DBの文章＋ID参照」から決定的に組み立てます（乱数なし）。

## 確定事項（2026-11-01 時点）

| 項目 | 中身 |
|---|---|
| EMS | E=Ends（目的）／M=Means（手段）／S=Structure（構造）。制約は構造に加える「〜せずに」「〜しながら」等の刺激要素 |
| 授業の流れ | EMS講義（軸）→ CATGame_GEN で猫の案 → Webプロトで遊ぶ（50分型）までが到達点 |
| 以降（検討中） | Webプロト作り込み60分 → Unity MCP で移植20分 → Unityroom公開。前提：Codex無料枠内・無料でなければOCではやらない |
| 入力方針 | 選択式＋「その他」自由記述。候補は実観察（癒し・ネギ・ひっくり返す等）を反映 |
| 猫の表現 | 実在の写真を使わない。図形（四角と三角）で描く。色は3色まで。鳴き声は「にゃー」だけ。音はWeb Audioで合成 |
| 保存 | localStorage、キーは `catgame.v1`。同じURLで続きから |
| 版の刻印 | HTMLに直接書く（JSで書き換えない）。点検ページを別に用意する |
| push | 先生がやる（エージェントはpushしない） |

## 構成（予定）

```
CATGame_GEN/
├ index.html        （本体：9ステップ＋役割バー）
├ assets/v1/        （data.js／plan.js／prompts.js／app.js／style.css）
├ tools/            （検証ページ：件数・参照切れ・同一出力・字数・公開確認）
└ docs/             （診断表などの設計文書）
```

## 開発ルール（PK//PROTO から継承）

1. 1回の変更は1テーマだけ。**データ → 判定 → 画面 → 出力** の順。画面から作らない
2. 目視で「できました」と言わない。実ブラウザで実行して数え、件数を報告する
3. 検証ページを必ず作る（URLで開ける形。先生が自分で再実行できるようにする）
4. 判定が FAIL したら、まず自分の検証ツールが間違っていないかを疑う
5. 数値でない制約は未記入として扱い、緑にしない
